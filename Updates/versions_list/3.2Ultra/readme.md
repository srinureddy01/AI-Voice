# 🎙️ Jarvis Voice Assistant

An intelligent, voice-controlled personal assistant built with Python. Jarvis can perform various tasks hands-free including telling time, searching Wikipedia, opening websites, setting timers, telling jokes, and more.

## ✨ Features

- 🎤 **Voice Recognition** - Listens for wake word "Jarvis"
- 🔊 **Text-to-Speech** - Natural voice responses
- ⏰ **Time & Date** - Tells current time and date
- 🌐 **Website Opener** - Opens Google, YouTube, GitHub, Gmail, or any custom website
- 📚 **Wikipedia Search** - Fetches quick summaries from Wikipedia
- ⏲️ **Timer Function** - Set countdown timers with notifications
- 😂 **Random Jokes** - Tells programming and dad jokes
- ☁️ **Weather Info** - Weather updates (simulated or real API)
- 🆘 **Help System** - Lists all available commands
- 🔄 **Continuous Conversation** - Stays active after wake word

## 📋 Prerequisites

Before running Jarvis, ensure you have the following installed:

- Python 3.7 or higher
- Microphone (built-in or external)
- Internet connection (for Google Speech Recognition)
